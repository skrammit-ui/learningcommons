Student Grouping Planner

Upload cluster scores → get student groups, what each cluster contains, and next steps. Math K–8, Common Core.

1. Add your class data

Drop a PRoPL CSV export, ISR PDF, or both or choose files

Files are read in this browser only. Student data is never uploaded.

One row per student. The first column is the student's name or ID. Each other column is a cluster code (such as 4.NF.B) with the student's score.

Student,4.OA.A,4.NBT.B,4.NF.A,4.NF.B
Ava R.,85,90,62,48
Mateo L.,72,55,80,77
  • PRoPL Individual Student Reports (PDF) work too, on their own or with the CSV. They add how many questions each student saw on each cluster. Students are matched across the two files by ID.
  • Scores can be percents (0–100), decimals (0–1), or fractions like 3/5.
  • Columns can also be standards (4.NF.B.3 or 4.NF.3); they're averaged into their cluster.
  • Headers can include extra text, e.g. 4.NF.B Build fractions from unit fractions.
  • A "long" file also works: one row per student per cluster, with columns Student, Cluster (or Standard), Score.

2. Adjust grouping

Load your class data above (or the sample) and these settings will appear here. Groups update as soon as you change one.

Clusters taught so far

Untick clusters you haven't taught yet. They're left out of grouping and next steps, and shown greyed out in the heatmap. · ·

Group these students (by overall score on taught clusters)

Groups are formed from each student's full pattern of cluster scores, so students who struggle with the same clusters land together. Changes apply right away, and your settings and moved students are saved in this browser for this class data, so uploading the same files again brings them back.
